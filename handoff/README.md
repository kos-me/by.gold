# gold.by — папка для разработки

## Что здесь

```
gold.by v2.dc.html      макет: главная (два состояния), /kak-proverit-otsenku, /o-proekte
support.js              рантайм макета — нужен, чтобы .dc.html открывался в браузере
image-slot.js           компонент слотов под фото (в продакшене не нужен, заменить на <img>)
images/*.webp           три готовых кропа, 900px, вместе 54 КБ
source-photos/*.png     оригиналы кадров — если понадобится другое кадрирование
HANDOFF.md              что осталось сделать: данные, шрифты, API формы, alt, лицензии
brief.md                исходный бриф заказчика
```

## Как посмотреть

Открыть `gold.by v2.dc.html` в браузере — файл самодостаточный, сборка не нужна.
Все три страницы переключаются в верхней навигации.

Два состояния главной — переключатель внизу страницы:
**«данные подтверждены»** и **«срок истёк»** (цена скрыта, калькулятор выключен).
Второе — ключевой экран, из-за него всё и построено; смотреть обязательно.

Состояния формы — на `/o-proekte`. Для проверки:
`.test` в адресе почты → сбой отправки, «41» в тексте → «уже в работе».

## Что переносить как есть

- Все цвета, размеры и отступы заданы инлайном в разметке — брать оттуда, отдельного файла токенов нет.
- Клеймо у цифры (повёрнутый штампик с номером постановления) — знак проверенных данных.
  Сплошная рамка = постановление действует, пунктир = действующего нет. Появляется только
  рядом с цифрами, у которых есть номер и дата; больше нигде.
- Формулировка результата расчёта: «стоимость по официальным ценам Минфина».
  Не «сколько вы получите» — итоговая сумма зависит от опробования и зачётной массы.
- Состояние «срок истёк» — не ошибка, а обычное состояние. Без иконок предупреждения,
  без извинений: что известно, что уточняем, ссылка на источник, старая цифра как архив.

## С чего начать

`HANDOFF.md`, раздел 1: контракт данных постановления и правило перехода в состояние
«срок истёк». Без него страница не работает — остальное вторично.
